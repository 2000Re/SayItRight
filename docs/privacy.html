Privacy Policy for SayItRight

Last updated: 2026

SayItRight is a personal, single-operator automation project that generates short pronunciation videos and uploads them to a single YouTube channel ("Say It Right") using the YouTube Data API and Google Cloud Text-to-Speech API.

Data we access

SayItRight accesses only the YouTube channel and Google Cloud project that belong to the project's own operator. It uses this access solely to:

  • Upload videos and thumbnails produced by this project to that channel
  • Set video titles, descriptions, tags, and translated (localized) metadata for those videos

No data belonging to any other user or third party is accessed, collected, or processed. SayItRight does not have a public sign-in flow, does not serve other users, and does not sell, share, or transfer any data to third parties.

Data storage

Operational data (which words have already been used to generate a video) is stored in the project's own source code repository. No personal data about end viewers of the published videos is collected.

Contact

Questions about this policy can be sent to the developer contact email listed in the associated Google Cloud project.
